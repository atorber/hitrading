## 会下单吗？会连券商吗？

不会。HiTrading 只做**行情读取、指标计算与分析展示**，不包含任何交易接口，也不保存券商凭据。持仓页只是本地记账。

## 数据准不准？

全部来自公开免费接口（腾讯 / 新浪 / 东方财富），抓取后做短时内存缓存（3–5 分钟）。**可能有延迟、缺失或口径差异**，请自行核实后再用于决策。插件内所有页面都带有相应提示。

## 自选股数据存在哪？

`~/.dsh/storages/hitrading.db`（SQLite）。控制台、Agent 工具、外部 HTTP 服务读写同一份。每小时自动生成 `.bak` 快照，误删可用它恢复（把 `.bak` 复制回 `.db` 即可）。

## 为什么强势股第一次点历史日期要等？

历史日期的「当日涨幅 >7%」需要全市场日K计算。首次点击会扫描约 5900 只股票（20 秒左右），一次扫描会把**全部历史日期**都算好并缓存；之后切换秒开。

## 量能里的「京市」为什么用北证50？

北交所没有覆盖全市场的指数，免费接口里唯一能拿到日成交额的是北证50（成分股口径，通常占北交所成交额一半以上）。页面与文档都标注了该口径，合计仍是「沪 + 深 + 京」。

## 控制台和服务（8099）是什么关系？

控制台通过 Harness 的鉴权路由工作，不依赖 8099；8099 是给**外部程序**用的独立服务。两者共用同一套操作实现和同一个数据库。头部按钮可以启停/重启 8099。

## 想给别的 Agent 用？

服务直接托管技能包：`curl -o <技能目录>/hitrading/SKILL.md http://127.0.0.1:8099/skill.md`，或把这句话发给目标 Agent 让它自己装。
