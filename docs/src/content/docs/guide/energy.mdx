## 页面构成

顶部切区间 **近20日 / 近40日 / 近60日**，右侧显示量能状态与更新时间（每分钟静默刷新）。

**9 张指标卡**：最新合计、较前日、5 日均额、区间均额、区间最高、区间最低、上证涨跌、创业板涨跌、科创50涨跌。

**趋势图**：柱=当日合计成交额，**红=上证收涨、绿=上证收跌**；折线=MA5（5 日移动均额）。纵轴自动取整，横轴标月份与最新日期。

**明细表**：日期 / 沪市(亿) / 深市(亿) / 京市(亿) / 合计(亿) / 较前日(亿) / 上证涨跌 / 创业板涨跌 / 科创50涨跌。「合计」「较前日」可排序。

## 量能状态怎么算

```
缩量/放量 = (最新交易日合计 ÷ 5 日均额 − 1)
       ≥ +10% → 放量
       ≤ −10% → 缩量
       其余  → 平量
```

5 日均额**含最新交易日**，与业界常用口径一致。

## 数据口径

| 市场 | 取数 |
| --- | --- |
| 沪市 | 上证指数成交额（全市场） |
| 深市 | 深证综指成交额（全市场） |
| 京市 | 北证50 成分股成交额（北交所无全市场指数，为此口径） |
| 合计 | 沪 + 深 + 京 |

盘中最新一根为**当日累计值**；收盘后自动定稿。数据源为东方财富 `push2his` 指数日K，缓存 3 分钟。
