信息流拆成四个独立 Tab，各自保留筛选状态，互不干扰。

## 快讯

<Shot name="news" alt="快讯页" caption="快讯：4 张指标卡 + 监管/宏观/行情分类 + 监管动态提醒 + 按日分组时间轴" />

- **指标卡**：快讯总数、最近 1 小时条数、监管动态条数、宏观条数
- **分类 chips**：监管动态 / 宏观 / 市场行情 / 其他，点一下只看该类
- **监管动态提醒**：有监管类快讯时，顶部出现红色提示卡，直接点名相关标题
- **时间轴**：按日期分组，每条左侧是时间、右侧标题 + 分类标签

勾选 **只看自选** 后，只保留标题或摘要里出现自选股名称的快讯（快讯正文通常只写公司简称，不写代码）。

## 公告

<Shot name="announcement" alt="公告页" caption="公告：七类公告分类 + 按代码查询 + 每条一键加自选" />

七类公告自动打标：

| 分类 | 关键词示例 |
| --- | --- |
| 业绩报告 | 业绩、季报、年报、预告 |
| 股权激励 | 激励、员工持股 |
| 投资并购 | 重组、收购、对外投资 |
| 增减持回购 | 增持、减持、回购、质押 |
| 分红派息 | 分红、派息、权益分派 |
| 融资发行 | 定增、非公开发行、可转债 |
| 公司治理 | 股东会、董事会、决议 |

- 输入 6 位代码可只看单只个股的公告（回车或点「查询」）
- 每条右侧 **+ 自选** 直接加入股票池
- **只看自选** 按代码 + 名称双匹配过滤

## 微博

<Shot name="weibo" alt="微博页" caption="微博：博主筛选、互动数、已提取标记与「提取股票」写入自选" />

对接本机 Weibo Crawler 服务（`127.0.0.1:15001`），展示已入库微博：

- **博主 chips**：全部 / 各博主切换
- **每条微博**：`@博主名` + 点赞/评论/转发数 + 正文（4 行截断）
- **已监控 / 已提取** 标记：来自自选股池的博主标「已监控」，模型处理过的标「已提取 N」
- **提取股票**：启动一个**后台任务**，把未提取的微博交给会话默认模型解析 A股标的，写入自选；已存在的只更新最后提及时间，已提取的微博不会重复处理
  - 任务在 Host 侧运行，**切 Tab、关面板、刷新页面都不会中断**
  - 按钮实时显示进度（`提取中 40/220`），运行中点击可停止
  - 一批失败会自动减半重试；模型输出被截断时按条目抢救，不影响已完成的部分
  - 结果落 SQLite，宿主重启会标记为「中断」，再点一次从断点继续
- 提取出的股票以 chips 形式挂在微博下方，点开自选即见

:::note
「提取股票」需要 Harness 内的模型通道，独立 `:8099` 服务不支持该操作。
:::

## 龙虎榜

<Shot name="lhb" alt="龙虎榜页" caption="龙虎榜：资金摘要 + 多空分歧榜 + 聚合明细表" />

- **资金摘要卡**：上榜家数、机构/营业部净买与净卖合计、分歧最大的个股
- **多空分歧榜**：中轴发散条形图，红色净买、绿色净卖，点行直接加自选
- **聚合明细表**：同一股票因多个原因上榜时合并（金额不重复计），可按净买额排序
- **只看自选**：只看自选股的上榜情况

## 预警

<Shot name="alerts" alt="预警页" caption="预警：价格/涨跌幅阈值规则，定时器巡检并标记触发状态" />

规则由四个条件之一组成：

| 条件 | 含义 |
| --- | --- |
| `price_above` | 价格上破阈值 |
| `price_below` | 价格下破阈值 |
| `pct_above` | 涨幅高于阈值（%） |
| `pct_below` | 涨幅低于阈值（%） |

规则持久化在本机 SQLite，交易时段由定时器巡检；触发后标记「已触发」并在行内高亮，不会重复提醒。
