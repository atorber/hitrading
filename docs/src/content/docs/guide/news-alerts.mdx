## 资讯

<Shot name="news" alt="资讯页" caption="资讯：A股快讯 / 个股公告 / 龙虎榜 三类切换" />

三类内容：

- **快讯**：A股市场实时快讯（东方财富）
- **公告**：个股公告，可按代码过滤
- **龙虎榜**：最近交易日上榜个股（净买额、买卖金额、上榜原因、换手率）

## 预警

<Shot name="alerts" alt="预警页" caption="预警：价格/涨跌幅阈值规则，定时器巡检并标记触发状态" />

规则由四个条件之一组成：

| 条件 | 含义 |
| --- | --- |
| `price_above` | 价格上破阈值 |
| `price_below` | 价格下破阈值 |
| `pct_above` | 涨幅高于阈值（%） |
| `pct_below` | 涨幅低于阈值（%） |

交易时段内由 Host 定时器每 60 秒巡检一次，命中后标记「已触发」并记录最近触发时间。提醒只在 GUI 内展示（不推送手机通知、不下单）。
