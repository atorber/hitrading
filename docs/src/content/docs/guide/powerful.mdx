## 布局

左侧是**最近 10 个交易日的日期列表**（最新在顶部，标「实时」），每项带当日强势股数量；右侧是选中日期的榜单。

点击日期切换；当前日期高亮。切回最新交易日即回到实时视图。

## 表格列

| 列 | 含义 |
| --- | --- |
| 当日涨幅 | 当日收盘 / 前一日收盘 − 1（前复权） |
| 涨停 | 东财涨停池：`涨停` 或 `N连板` |
| 首封时间 | 首次封板时间 |
| 行业 | 东财行业板块 |
| 最新涨跌幅 | 该股**当前**实时涨跌幅（隔日视角看是否延续） |

「当日涨幅」「涨停」「最新涨跌幅」可排序；每行可一键 `+ 自选`。

## 性能与缓存

- **最新交易日**：东财涨幅榜实时翻页（按涨幅降序，翻到 ≤7% 即停）——秒开
- **历史日期**：首次点击触发一次**全市场日K扫描**（约 5900 只，20 秒左右），一次扫描同时填满全部历史日期并写入 SQLite
- 之后任意日期切换都是**秒级**（读缓存）

:::tip[常用建议]
想每天开盘前看昨日强势股？前一天收盘后进一次该 Tab，数据会以收盘口径定稿缓存，第二天直接秒开。
:::
