## 排序与过滤

**排序字段**：涨跌幅 / 成交额 / 换手率 / 总市值。

**区间过滤**（可叠加）：

| 参数 | 说明 |
| --- | --- |
| `pctMin` / `pctMax` | 涨跌幅区间（%） |
| `peMin` / `peMax` | 市盈率区间 |
| `mcapMinYi` / `mcapMaxYi` | 总市值区间（亿元） |
| `turnoverMin` | 换手率下限（%） |

结果表支持行内勾选与全选，**批量加入自选**（已存在的会提示）。

数据来自新浪全市场列表（`Market_Center.getHQNodeData`），约 5000+ 只，带 PE/PB/市值/换手。
