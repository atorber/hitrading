## 添加自选

顶部「添加（名称/代码）」支持三种输入：

- **名称/拼音/代码模糊搜索**：输入「茅台」「gzmt」「600519」都会出候选下拉，↑↓ 选择、回车确认
- **批量粘贴**：`600519,000001 300750`（逗号、空格、换行都行），一次加入多只
- 加入时可同时指定**关注度**和**标签**

已存在的股票不会重复添加，原关注度与标签保留。

## 关注度与标签

**关注度**分三级：基础股 / 精选股 / 交易股（默认基础股）。行内下拉可随时改。

**标签**每只最多 10 个、单个 ≤12 字，可点标签编辑浮层批量增删：

- 已有标签以胶囊列出，点一下即添加
- 输入新标签回车添加，× 移除
- 标题栏「标签」列可打开浮层，表格上方还有一行**标签快速筛选**（点一下只看该标签，再点取消）

**筛选**同时支持表头多选（关注度/标签列的小漏斗）与顶部快筛选行，两处共享同一状态。

## 涨跌幅列

| 列 | 含义 |
| --- | --- |
| 最新涨跌幅 | 现价 vs **昨收**（当日涨跌） |
| T-1 … T-30 | 现价 vs **T-(n+1) 日收盘**的累计涨跌幅（近 n+1 个交易日） |

所有涨跌幅列都可点表头三态排序（降序 → 升序 → 取消），数值缺失的行自动沉底。

## 个股详情

点代码打开详情卡：现价、市盈率、市净率、市值 + MA5/MA10/MA20/MA60、MACD、RSI14、KDJ，并附 **60 根日K蜡烛图**。

:::note[数据口径]
行情来自腾讯 `qt.gtimg.cn`（GBK 解码），新浪 `quotes.sina.cn` 兜底；T-n 用新浪日K前复权收盘计算，日内缓存 5 分钟。
:::
