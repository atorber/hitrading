## 全局约定

- **红涨绿跌**：与 A股行情软件一致。
- **数值右对齐 + 等宽数字**：表格里的价格、涨幅、金额都用 `tabular-nums` 对齐，便于纵向比较。
- **静默刷新**：定时刷新只替换数据，不重挂表格——滚动位置、筛选、标签浮层都不受影响。
- **刷新按钮**：每个页右上角的 ⟳ 可手动拉取；拉取中图标旋转。
- **失败不丢数据**：刷新失败保留上一份数据，右上角显示「刷新失败」，悬停看原因。

## 服务状态与启停

控制台头部常驻服务灯：绿点表示 `127.0.0.1:8099` 可用。旁边的 **启动 / 停止 / 重启** 按钮控制这个本地服务——外部程序（Python/R）通过它读写数据。

:::note
控制台本身不依赖该服务：即使服务停了，GUI 里的 Tab 仍通过 Harness 的鉴权路由工作。
:::
